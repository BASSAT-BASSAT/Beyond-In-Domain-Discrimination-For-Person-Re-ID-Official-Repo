The loss is not interchangeable

The same ArcFace settings raise ConvNeXt-S by 2.6 mAP and lower OSNet by 1.6. OSNet with the default loss is still the best accuracy per parameter: 43.6% mAP from 1.9 million deployed weights.

What the curves show

Training used 782,064 images and 10,036 identities. Checkpoints were chosen on held-out identities from those sources, never on the four public benchmarks. The first public weights will be Strong Baseline with ArcFace, and OSNet with Circle-softmax plus triplet, at reid-research-hub.
