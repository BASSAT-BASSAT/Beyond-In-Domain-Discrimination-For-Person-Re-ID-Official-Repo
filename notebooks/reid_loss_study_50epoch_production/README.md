## Shared setup

- 50 virtual epochs × 2,000 steps = 100,000 updates
- 2× T4, batch 128
- Kaggle dataset `a7medlabib/reid-fine-tunning-datasets-v3`
- Secrets: `GITHUB_TOKEN`, `HF_TOKEN`
- Checkpoints: private bucket `reid-research-hub/reid-loss-study-live`. The remote folder name is the checkpoint key printed in each notebook. Not committed to git.

Do not run two sessions for the same notebook.

## Paper evaluation

[`ReID_Paper_HeldOut_Evaluation.ipynb`](ReID_Paper_HeldOut_Evaluation.ipynb) downloads `model_best.pth` and evaluates Market-1501, MSMT17, DukeMTMC-reID, and Occluded-Duke from `a7medlabib/reid-unseen-evaluation-targets-v1`. Rebuild it with `python scripts/build_heldout_eval_notebook.py`.
